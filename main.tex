\section*{Impact Statement}
This paper presents work whose goal is to advance the field of machine learning by making large-scale unbalanced optimal transport practical in linear memory on a single GPU.
The main broader effect we expect is a lower computational and energy cost for the same analysis; we see no further societal consequences that require separate discussion here.
